# IC-7447-Logic-Implementation-in-Verilog
implementation of IC 7447 Logic i.e. BCD to 7 segment decoders
Proud to share my latest VLSI project where I implemented the logic of the IC 7447 – a BCD to 7-segment display decoder – using Verilog HDL!

✨ Key Features: ✅ Accurate BCD to 7-segment conversion logic modeled and simulated. 🔄 Implemented and validated Ripple Blanking Input (RBI) and Ripple Blanking Output (RBO) logic — crucial for cascading multiple decoder ICs. 🧪 Verified output logic through functional and timing simulations. 🛠️ Visualized design through RTL schematic and netlist view. ⚡ Power Summary: Total On-Chip Power: 1.532W Dynamic: 1.448W Static: 0.084W

📊 Simulation includes: Handling LT (Lamp Test), RBI, and RBO inputs/outputs. Logic zero blanking and propagation through RBO pin. Clean waveforms showing correct segment output per BCD input. 🛠 Tools Used: • Verilog HDL • Xilinx Vivado

💡 This project enhanced my understanding of decoder ICs, cascading behavior via RBI/RBO, and real-time VLSI design optimization.
